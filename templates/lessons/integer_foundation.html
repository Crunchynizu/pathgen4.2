2-minute recap

Every integer has a place on the number line

Zero is in the middle. Positive integers go right, negative integers go left, and numbers get greater as you move right.

Worked example

Is -11 an integer? What is its opposite? What is |-11|?

  1. -11 has no fraction and no decimal, so it is an integer.
  2. The opposite of -11 is 11: same distance from zero, other side.
  3. |-11| = 11, because -11 is 11 units from zero.

Integer: yes. Opposite: 11. Absolute value: 11.

Number line: what is an integer?

An integer is a whole number. It can be positive, negative, or zero. It has no fraction and no decimal part.

  • -8, -3, 0, 5 and 12 are integers.
  • 3/4, 0.6 and 12% are not integers.

We use negative numbers every day. A temperature 3 degrees below zero is -3. A debt of 500 pesos is -500. A diver 6 meters under the sea is at -6.

On a number line, a point 4 units to the left of 0 is at -4, and a point 4 units to the right is at 4.

Opposites

Opposites are two integers the same distance from zero, on different sides. -5 and 5 are opposites. To find the opposite, keep the number and change the sign.

  • The opposite of 9 is -9.
  • The opposite of -2 is 2.
  • Zero is its own opposite.

Absolute value

Absolute value is the distance from zero. A distance is always positive or zero. We write it with two bars: |6| = 6, |-6| = 6, |0| = 0.

To compare absolute values, find each distance first: |-12| = 12 and |9| = 9, so |-12| > |9|.

Common mistake

|-8| = -8 is wrong. Absolute value is a distance from zero, so it is never negative. Correct: |-8| = 8.

Compare and order

Values increase as you move right, so -9 < -2 < 0 < 4. Compare by position, not by the size of the digits: -9 is less than -2 because it is farther left.

Worked example

Order 4, -6, 0 and -1 from least to greatest.

  1. Place each number on the number line. -6 is farthest left and 4 is farthest right.
  2. Between them, -1 is left of 0.
  3. Read the numbers from left to right.

-6, -1, 0, 4

Common mistake

-9 > -4 is wrong. The digit 9 is bigger, but -9 is farther left. Correct: -9 < -4.

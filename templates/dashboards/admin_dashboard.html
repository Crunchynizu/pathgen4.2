Setting up a class

  1. Create the teacher's account.
  2. Create the class and assign that teacher.
  3. Add the students: one at a time on Accounts, or a whole class with manage.py create_study_class, which also writes login slips.
  4. Give the class its practice with manage.py import_bank --teacher <username> --class "<class>".
